# STA 公告与移动动效预览

从仓库根目录启动静态服务器后，打开 `/design/notice-lab/`。

这是一份独立交互设计稿。预览加载当前主站的 HTML、CSS、JS 与云端文案，在隔离的 iframe 中插入公告设计。顶部可切换电脑/手机、定位公告/部门/首屏、重播动效。

公告示例的文字、日期和图片取自主站本次实际加载的云端活动内容，页面明确标注为版式演示。未新增真实公告，也不写入云端。预览仅在内存中跳过主站的长开屏和访问统计，便于直接审阅新增设计；源文件与正式主站不受影响。

体验重点：纸层与图片错落展开、飞镖入场、悬浮轻微透视、类别切换、公告阅读弹层、图片全屏/缩放/切换，以及手机部门书封和活动横滑指示。减少动态效果时保留全部阅读与操作能力。

文件：`host.js` 负责整站预览容器；`preview.js` 与 `preview.css` 负责方案呈现。正式公告发布与管理功能需在设计确认后另行接入。

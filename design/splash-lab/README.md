# STA Splash Lab · 开屏动画实验室

5 个开屏加载动画概念的可交互演示，用于选定正式方案。
自包含单文件（`index.html`），零第三方依赖，直接静态托管即可。

## 访问

本地服务器启动于仓库根目录：

```
python -m http.server 8940 --bind 127.0.0.1
```

打开：<http://127.0.0.1:8940/design/splash-lab/>

## 五个版本

| # | 名称 | 一句话 | 时长 |
|---|------|--------|------|
| 01 | 银河列车 GALAXY EXPRESS | 进度条就是铁轨，列车驶过亮起的轨段，到站发车 | ~4.7s |
| 02 | 星轨罗盘 ORBIT COMPASS | 三颗彗星画出轨道，收束成 STA 徽标 | ~3.9s |
| 03 | 星尘成字 STARDUST MORPH | 星尘先凝成「1999」再重组为「STA」，可光标拨动 | ~4.6s |
| 04 | 曲率航行 WARP TRANSIT | 第一人称超光速航行，词句迎面飞掠，虹膜开孔抵达 | ~4.4s |
| 05 | **星环列车 STELLAR ORBITAL** ★ | 全息粒子列车贴巨型斜椭圆星环渐进加速绕行，俯冲途中逐渐散开、撞屏碎裂，车体光点与星环尘埃汇成「STA」，幕布升起揭示正式首页 | ~7.2s |

> 05 为「银河列车 × 星尘成字」合体方案：土星环式对角构图（长轴右端抬起 -15°、后仰 66°），
> 列车是真三维点云（透视近大远小、转弯自然变形），从上方深处迎面放大 → 底部近景掠过 →
> 沿切线加速冲出画面解体成光流 → 连同星环尘埃一起被吸进 STA 字形 → 闪光揭幕。

## 控制方式

- 顶栏胶囊切换版本；`←` `→` 切换；`R` 重播；`S` 循环切换 1× / 0.5× / 0.25× 慢放
- `ℹ` 打开当前版本的设计说明（核心意象 / 节奏曲线 / 惊喜点 / 实现成本）
- 每次动画结束会揭开出「站点假想页」，模拟真实交接效果

## URL 参数（审阅辅助）

- `?v=a|b|c|d|e` — 直达某版本
- `&t=2.4` — 冻结在第 2.4 秒逐帧审阅（C/E 版会自动等字体采样就绪再冻结）
- `&speed=0.25` — 以慢速播放

### E 版推荐审阅帧

`t=0.7` 星尘旋入凝环 · `t=1.7/2.6` 近景掠过 · `t=4.1/4.3` 俯冲散开 · `t=4.55` 撞击碎裂 · `t=5.1` 汇聚成字 · `t=6.0` 成形停留 · `t=7.35` 揭幕正式首页

## 落地要点（接入 sta-web 主站）

1. 现有 `.preloader`（数字 + 进度条）整体替换为新结构的挂载节点；
   `js/main.js` 的 `initPreloader()` 中 GSAP 计数逻辑替换为对应版本的 rAF 时间线，
   `finish()` 时机对齐各版本 `dur`（A: 4.7 / B: 3.9 / C: 4.6 / D: 4.4 / E: 7.2s）。
2. 所有动画是时间 t 的纯函数（粒子版内部状态除外），天然支持页面加载中途的降速/跳过。
3. `prefers-reduced-motion` 建议直接跳到终帧揭示。
4. 性能：A–D 均为单 canvas ≤400 粒子或纯 SVG/DOM；E 版峰值约 1600 点（车身 450 + 星环 430 + 彗尾/火花池 + STA 720），
   全部单 canvas additive 绘制，DPR 上限 2，移动端建议把 `sampleTextPts` 步距放大一档即可。
